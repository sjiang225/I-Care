# R02 / R10：教育资料目录与正文引用

2026-09-29。对应会议纪要 R02（全部教育手册/主题入口）和 R10（引用编号直达对应资源）。

## 用户流程

- 首页提供 Browse guides & videos，顶部入口为 Library（视频加入前名为 Guides）；四项导航均使用图标和文字。
- 目录复用 `backend/app/kb/sources.json` 的 25 份英文手册和 `backend/app/tools/data/videos.json` 的全部 12 条视频，共 37 项、11 个主题。视频为 10 条英语、1 条西班牙语、1 条俄语，逐项标明语言并保留现有资料标题。
- 默认 All，可切换 Guides / Videos；类型、主题、标题/主题/语言搜索可以组合使用。清空筛选恢复全部资料；支持加载、失败重试、无结果提示。
- 手册在新标签页打开原始 PDF，视频打开对应 YouTube 页面；目录本身不嵌入播放器或加载缩略图。无需注册、聊天、调用模型或填写自评。目录页保留官方手册与视频总页链接。
- 同一打开页面内切换 Home / Chat / Library / Self-assessment，保留聊天草稿、自评状态、目录搜索、类型/主题筛选及滚动位置；浏览器后退/前进支持 `#library`。
- 回答中的 `[1]`、`[2]` 及逗号/分号分组编号可以点击，链接来自**该条回答的来源元数据**，与底部 Sources 一致；编号具有来源名称及新标签页提示。

## 引用与历史

`remarkCitations` 在 Markdown 文本节点上建立链接，保留列表、强调、表格等格式，不改写代码、已有链接或链接定义。找不到来源、没有有效网页链接、编号冲突或来源元数据缺失时，保留普通文字；不通过全目录序号或重新检索猜测链接。流式回复过程中来源更新会触发渲染。

登录用户的新回答将来源编号、标题、类别、URL 与回答一同保存，`GET /api/history` 返回来源供页面恢复。服务端保存的是本轮检索产生的来源，不接受客户端指定来源。旧 `messages` 表仅新增 `sources TEXT NOT NULL DEFAULT '[]'`；旧内容和记录保留。旧回答未保存过来源，无法可靠补齐其引用。

已有会话 ID 必须属于当前登录用户，否则返回 404，防止把回答及引用写入他人会话。游客聊天仍不持久化。

## 实现与检查

- `backend/app/api/library.py`：公开只读目录接口，保留原 `documents` 字段并新增 `videos`；主题覆盖两类资料的并集。
- `backend/app/tools/resources.py`：`load_videos()` 供目录和聊天共用。目录不套用聊天的数量/语言限制；`pick_videos()` 仍默认按主题推荐最多 2 条英语视频。
- `frontend/components/GuideLibrary.tsx`：目录、搜索、筛选和状态保留。
- `frontend/lib/citations.ts`、`frontend/components/Markdown.tsx`：按本条来源映射正文引用。
- `backend/app/db.py`、`backend/app/api/chat.py`、`backend/app/api/history.py`：兼容迁移、引用保存和恢复。
- `backend/tests/test_library_and_citations.py`：目录完整性、来源编号、历史恢复、旧库兼容、游客不落库及账号隔离。
- `frontend/tests/citations.test.mjs`：真实 Markdown 渲染下的普通/分组编号、列表/表格、流式不完整编号、代码/已有链接、未知或不安全来源。

## 原有问题与变更

原 Home 按钮只在出现聊天消息后显示，实际上调用清空对话逻辑；自评页面只有 Back to chat，缺少相同位置的首页入口。

现在首页、聊天和自评共用顶部导航：**Home / Chat / Self-assessment**，始终显示文字和图标，以背景、底线和 `aria-current="page"` 标明当前位置。导航与品牌区固定在内容滚动区上方。手机三列排列，图标上、文字下；桌面横向图文排列。

首页提供清楚的 Start chatting 入口；已有会话或草稿时显示 Continue chatting。自评作为第二张入口卡，主题建议作为下方独立区域，并说明可以询问其他照护主题。First time here? 可展开三步简短说明，包含提问、发送、查看来源和返回首页；这属于本轮起步引导，并不代表会议 R03 的完整使用指南已经全部完成。

选择主题只预填建议问题，不自动发送。已有草稿时保留原内容，显示 Keep my draft / Use suggested question 供用户选择。聊天输入框具有可见标签，Speak、Send 同时显示图标和文字。

## 返回与保留规则

- Home 只切换页面，不清空聊天、输入草稿或当前会话 ID。
- 三个面板保持挂载；隐藏面板不参与键盘或屏幕阅读器导航。自评内部页、选项、临时结果、首页指南展开状态与滚动位置在内部导航时保留。
- 浏览器地址使用 `#home`、`#chat`、`#self-assessment`，后退/前进同步切换面板。
- 回复生成中仍可导航，生成继续；回到聊天可看到完整回复。离开聊天会停止朗读/语音输入，避免导航后继续播放。
- New conversation 是独立操作；先显示页内确认，默认聚焦 Keep this conversation，明确说明会清空当前屏幕的对话和草稿。确认后才重置当前会话；不删除数据库里的已保存记录。
- 这些保留规则适用于同一打开页面内的导航，不是浏览器持久化。刷新、关闭或账号切换不承诺保留草稿、游客会话或未提交问卷；登录用户仍使用原有的最新会话恢复与自评记录功能。

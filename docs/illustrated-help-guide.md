# R03：图示使用指南

2026-09-29。按会议 R03 及用户确认的图示方案实施。

## 入口与内容

首页介绍下方新增 **How to use I-Care** 入口，顶部品牌栏加入始终可见、带文字的 **Help** 按钮。用户主动打开，首次进入不强制弹窗。原先简短的文字折叠说明由完整指南替代。

| 教程 | 内容 |
| --- | --- |
| Getting started（4 步） | Start chatting；输入/Speak/Send；读回复、打开引用/Sources/Related videos；返回 Home 与继续聊天 |
| Guides & videos（2 步） | Library 入口、All/Guides/Videos、搜索、主题和语言；阅读资源卡、在新标签页打开和返回 |
| Self-assessment（2 步） | 选择 PHQ-9/GAD-7/PSS-10、自愿参与和登录时机；回答、提交、查看结果、游客与账号保存区别 |
| Your account（3 步） | 登录可选、游客不保存；登录／注册表单与密码提示；登录后恢复最近对话、保存自评结果，登录会替换屏幕上的游客对话，以及 Sign out 位置 |

每步使用当前程序的局部截图、箭头与边框高亮、独立于图片的可读说明，以及 Previous / Next 与步数。图片有替代文本，示例不是交互控件；完整操作仍在原页面进行。顶部可以切换教程，四步入门结束时也提供两个补充教程入口。

明确解释资源会打开新浏览器标签，返回需关闭资源标签或切回 I-Care；Home 不清空聊天，New conversation 需要确认；刷新或关闭不保留草稿、游客聊天或未提交问卷。自评说明只介绍现有操作，没有修改题目、计分、结果建议或临床触发规则。

## 状态和可访问性

- 使用原生 modal `dialog.showModal()`，底层页面保持挂载并暂时不可交互，不改变当前 URL、会话、草稿、目录筛选或问卷。
- Close、Escape、最后一步 Back to I-Care 关闭指南，键盘焦点返回打开指南的按钮。
- 打开与切换步骤时聚焦包含“Step n of m”的标题，指南正文滚回顶部；键盘 Tab / Shift+Tab 留在弹窗内。
- Previous 在第一步禁用；关闭按钮与页脚始终可见，正文单独滚动。
- 打开指南会停止当前朗读与语音输入，避免继续录入；不会取消后台回复。
- 桌面截图与文字并排，手机上下排列，三个教程按钮保留文字。320px 下压缩品牌栏间距及登录按钮图标，保留 Help / Sign in 文字。

## 实现与素材维护

- `frontend/components/HelpGuide.tsx`：教程内容、弹窗、步数、焦点与退出。
- `frontend/components/Chat.tsx`、`HomeView.tsx`：两个入口。
- `frontend/app/globals.css`：弹窗、截图高亮、手机布局。
- `frontend/public/help/*.png`：11 张截图，统一为手机版界面中 390×360 的区域、按 2 倍分辨率输出（780×720），要点击的控件用红框标出；弹窗大小固定，切换步骤时不变。
- `frontend/scripts/capture-help-screens.cjs`：可重复生成截图的 Node 脚本，使用本机 Chrome 和独立的游客会话。前后端运行时，在 `frontend/` 执行 `npm i --no-save playwright-core` 后运行 `node scripts/capture-help-screens.cjs`，直接覆盖 `public/help/` 中的图片。

截图从真实 UI 截取。聊天示例使用浏览器拦截的合成回复，不调用真实模型；目录和问卷使用现有公开读取接口，没有提交测评或使用真实用户数据。界面标签、组件或资料数量变化后，需要重新生成相关截图并目视检查。
